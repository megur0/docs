# Chromeの検索バー
* アドレスバーに1単語だけ入力すると、Chromeはそれをイントラネット上のホスト名である可能性も考慮し、裏側でその単語に対するDNS名前解決を試みる（「イントラネットリダイレクト検出」という仕組み）。名前解決に成功すると「もしかして http://入力した単語/ 」という案内バーが表示される。
  * これは全端末に対するmDNSのブロードキャストではなく、設定されているDNSサーバーへの通常の（ユニキャストの）問い合わせである。
  * ただし、暗号化されていないDNS通信の場合、この問い合わせ内容（＝入力したキーワード）は経路上でパケットキャプチャツールを使っている人に見られる可能性がある。
  * そもそも社内LANや公共のWi-Fiであれば、ネットワーク管理者からは通信内容が把握されうるが、この話は管理者以外でもパケットキャプチャツールを使っている人には筒抜けになっている、という話。
  * (参考) https://github.com/chromium/chromium/blob/main/chrome/browser/intranet_redirect_detector.cc
* 先に`?`を入力すると、常に検索として扱われ、上記のホスト名判定は行われないはず(?)。
